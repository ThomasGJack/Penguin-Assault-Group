# Commandes du chat — ce qui reste, et où se font les actions

Depuis la 1.0.12, le chat ne sert plus qu'à ce qui n'a pas d'équivalent en jeu. Tout le reste se fait sur place, pour le RP : on ne commande pas depuis sa radio, on passe par l'ordinateur.

## Les cinq commandes du chat

| Commande | Effet | Qui |
|---|---|---|
| `/aide` | liste ces commandes et rappelle où sont les actions | tous |
| `/mp <pseudo> <message>` | message privé à un joueur en ligne | tous |
| `/lier <code>` | lier son compte Discord, code donné par `/lier` sur le Discord | tous |
| `/charte` | relire la charte ; `/charte accepter` l'accepte | tous |
| `/admin` | ouvre le menu Staff si la touche F10 n'est pas disponible | Staff |

Une ancienne commande tapée au chat répond par l'endroit où faire l'action, par exemple : « Plus de commande /grade : menu Gestion du soldat, en regardant le joueur (F) ».

## Où se fait chaque action

| Action | Où | Qui |
|---|---|---|
| Voir les effectifs, sa fiche, la fiche d'un joueur, les instructeurs, le journal | ordinateur (PC), onglets Effectifs, Ma fiche, Instructeurs, Journal | tous |
| Missions : liste, détails, accepter, annuler | PC, onglet Missions ; tableau des missions pour consulter | accepter : Chef de groupe, Sergent et plus, officiers, Staff ; annuler : le chef, un officier, le Staff |
| Territoire, coffre, dépôts, parc auto, balises GPS | PC, onglets Territoire et Base | tous |
| Corps de joueurs déconnectés, promotions en attente | PC, onglet Officiers | officiers |
| Accorder ou retirer une certification | Gestion du soldat, en regardant le joueur | instructeur habilité pour cette certif, Staff |
| Promouvoir, rétrograder, créditer une mission | Gestion du soldat | officiers |
| Habiliter un instructeur pour une certification | Gestion du soldat, section « Instructeur de… » | Adjudant, Staff |
| Acheter un véhicule ou des paquets | terminal logistique, à l'atelier | tous, ou officiers seulement selon le réglage |
| Avertir, expulser, bannir, débannir, donner le Staff | menu Staff (F10), onglets Joueurs et Serveur | Staff |
| Grades forcés, certifications sans vérifier l'arbre, habilitations, téléportation, soin | menu Staff, onglet Joueurs | Staff |
| Créer, annuler, réussir une mission ; générateur à zéro | menu Staff, onglet Missions | Staff |
| Capturer ou perdre un secteur, lancer une attaque, territoire à zéro | menu Staff, onglet Territoire | Staff |
| Dépôts, coffre, caisses, flotte | menu Staff, onglet Logistique | Staff |
| Heure, vitesse du jour, civils, IA, sauvegarde, charte, pont Discord | menu Staff, onglet Serveur | Staff |
| Remises à zéro, wipe complet | menu Staff, onglet Danger, en deux clics | Staff |

## Depuis Discord (PAG-Bot, rôle Staff)

`/ban`, `/unban`, `/kick`, `/grade`, `/certif`, `/instructeur`, `/staff`, `/avertir`, `/dire`, `/mp`, `/sauver`, `/info`, y compris sur les joueurs hors ligne. Pour tous : `/serveur`, `/joueurs`, `/lier`, `/delier`.
